### Coverage notes for part C

Every phase 3 requirement in this part's scope is built by at least one slice above. Points a reader should know:

- REQ-INT-016: by part C, LTI 1.3 is built in phase 4 under Platform's Lti use case; QTI 3, Open Badges 3.0 and CASE are built in phase 5 by part D.
