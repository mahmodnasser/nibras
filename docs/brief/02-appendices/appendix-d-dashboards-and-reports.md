# Appendix D. Dashboards, Reports, and KPIs per Role

> Part of `docs/brief/02-appendices/`. Normative. Read with the master brief and the reference architecture.

Every dashboard card answers one question and links to one action. Cards respect permissions and data scope.

| Role | "Today" and action cards | Key indicators |
|---|---|---|
| **Platform operator** | Provisioning in progress, failing services, queue alarms, tickets at risk, trials ending | Tenants by plan, active students, MRR, churn risk, uptime, p95 latency, failed messages |
| **Owner or group director** | Campuses needing attention, approvals above limit | Enrollment vs capacity, collections vs target, attendance, staff turnover, satisfaction, results trend, per campus comparison |
| **Principal** | Approvals, unmarked attendance, staff absences and cover, incidents today, at-risk students, overdue grading, visitors on site | Attendance rate, punctuality, behavior trend, request SLA, fee collection, syllabus coverage |
| **Academic coordinator** | Lesson plans to review, marks to moderate, late mark entry, homework load warnings | Coverage by subject, grade distributions, teacher comparison, assessment completion |
| **Teacher** | Next class, attendance to mark, submissions to grade, messages, meetings, substitutions | Class averages, missing work, attendance per class, my grading turnaround |
| **Homeroom teacher** | Absent today, excuses to review, flags for my class, birthdays | Attendance, behavior, and performance overview per student |
| **Registrar** | New inquiries, applications per stage, documents missing, offers expiring, seats left | Funnel conversion, time in stage, re-enrollment rate, capacity utilization |
| **Accountant** | Payments to reconcile, refunds to approve, cheques due, overdue ladder today | Collections today and month, aging buckets, discounts granted, forecast |
| **HR officer** | Leave to approve, documents expiring, probation ending, vacancies | Headcount, absence rate, turnover, PD hours |
| **Counselor, nurse** | Referrals, follow-ups due, visits today, medication schedule | Caseload, visit reasons, intervention outcomes |
| **Parent** | Per child: today's status, what is due, fees due, requests, unread messages, upcoming events | Attendance, recent grades, behavior points, balance |
| **Student** | Today's timetable, due soon, new feedback, announcements | My grades trend, attendance, badges |

**Report library (minimum):** attendance registers and summaries; chronic absence; marks sheets; grade distributions; result analysis; honor roll; promotion list; report cards and transcripts; class lists with photos; teacher workload; timetable prints; substitution history; admissions funnel; enrollment statistics by grade, gender, nationality; re-enrollment; fee collection; aging; defaulters; discounts and scholarships; cashier day close; tax; behavior by category; clinic visits; request volume and SLA; communication reach; staff leave balances; document expiry; transport lists; library circulation; audit and access reviews; data quality; tenant usage.
