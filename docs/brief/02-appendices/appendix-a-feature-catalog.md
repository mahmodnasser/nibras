# Appendix A. Feature Catalog per Module

> Part of `docs/brief/02-appendices/`. Normative. Read with the master brief and the reference architecture.

Every module also includes, without repeating it below: list with search, filters, sorting, saved views, and column chooser; create, edit, archive, restore; bulk actions; import and export where data is bulk; custom fields; attachments; comments and activity history; audit trail; permissions and data scopes; notifications; both languages; web and, where relevant, mobile.

### A1. Platform and Tenancy

- Tenant signup, trial, provisioning saga with live progress, activation, suspension (read-only), reactivation, export, deletion with a cooling-off period
- Plans, add-on modules, limits, usage metering, overage warnings, coupons, tenant invoices, payment records, dunning
- Feature flags per tenant, per plan, and by percentage rollout
- White-label: logo, colors, login page, email sender name, custom domain with automatic TLS, mobile flavor configuration
- Platform announcements, maintenance windows, release notes, in-app changelog
- Support desk: tickets from tenants, SLA, canned replies, consent-based impersonation with banner and audit
- Tenant health score, adoption analytics, churn-risk flags
- Global template library (request types, report cards, certificates, notification templates, grading schemes) that tenants can copy
- **Rules:** a tenant can always export its data; deletion is a saga across all services with a final certificate of deletion; the platform operator cannot read tenant data without an audited, consented impersonation session.

### A2. School Setup and Configuration

- School profile, legal details, contacts, logo, stamps and signatures for documents
- Campuses, buildings, rooms with type and capacity, facilities
- Academic years, terms, grading periods, non-teaching days, holidays per campus, work week, bell schedules including special schedules
- Stages, grade levels, sections, subject catalog, departments, houses
- Grading schemes, assessment structures, report card templates per stage
- Numbering formats (student, staff, invoice, receipt, certificate, request)
- Terminology overrides, languages, currency, tax settings, time zone
- Onboarding wizard with progress checklist and sample data option
- **Rules:** only one current academic year per campus; a closed year is read-only except through an audited reopen; deleting configuration in use is blocked, archiving is allowed.

### A3. Identity, Access, and Admin Console

As specified in Section 10 of the master brief, plus: passkeys, TOTP, recovery codes; login by username, email, or phone; OTP login for parents (optional); account linking across tenants for one person; username policy; session list with remote sign-out; login alerts; API keys and personal access tokens with scopes and expiry; service accounts; webhook management with signing secrets, retries, and delivery log.

### A4. Request Center and Workflow Engine

As specified in Section 11, plus: request numbering per type; draft autosave; duplicate detection; requester on behalf of another person (a registrar for a parent); attachments with required-document rules; request fee linked to Finance; calendar impact preview (leave overlaps); printable request summary; public request link for non-users where a school allows it (for example, a former student requesting a transcript), protected by OTP.

### A5. Tasks and Notification Center

- Personal to-dos, tasks assigned by others, tasks generated by workflows, checklists, due dates, reminders, recurring tasks
- One inbox: notifications, approvals, mentions, tasks; filters; mark all read; snooze
- Staff duty rosters (gate, break, bus, exam invigilation) with swap requests *(T2)*

### A6. Admissions CRM and Enrollment

- Inquiry capture (web form, walk-in, phone, campaign source), lead stages, follow-up tasks, school tour booking, open-day events
- Online application with save and resume, dynamic form per grade, age eligibility rules per grade, required documents per grade and nationality, application fee
- Pipeline board, scoring, assessment and interview scheduling with slots, evaluator forms, committee decision, conditional offers, offer letters, deposit, expiry of offers
- Waiting lists with ranking and automatic promotion when a seat opens; seat capacity planning per grade and section
- Sibling and staff-child priority rules; duplicate applicant detection
- Enrollment: student number, section assignment, fee plan, transport, accounts, welcome pack, document checklist
- **Annual re-enrollment:** campaign, parent confirmation, seat hold, block on outstanding fees per policy, not-returning reasons, retention analytics
- Admissions analytics: funnel, conversion by source, time in stage, lost reasons
- **Rules:** capacity cannot be exceeded without an override permission and reason; an offer expires automatically; accepting creates student and guardian records through a saga.

### A7. Student Information

- Profile: bilingual names in culturally correct parts, photo, date and place of birth, nationality, identifiers, languages, religion where the school requires it for curriculum, previous school
- Guardians with relationship, custody and access rights, communication preference, payer flag, emergency contacts ordered by priority, authorized pickup persons with photos
- Medical summary visible to permitted staff: allergies, conditions, medications, emergency instructions, with an alert badge
- Documents with type, expiry, and reminder (passport, residency, vaccination record)
- Siblings, houses, clubs, transport, locker, ID card with QR
- Academic history per year, status timeline (applicant, enrolled, suspended, withdrawn, transferred, graduated, alumni)
- **Student 360** timeline; notes with visibility levels
- Bulk: promotion, section change, status change, ID card printing, photo upload by file name
- **Balanced class formation** tool *(T2)*
- Merge duplicates; data quality indicators per record
- **Rules:** status changes are workflows, never a field edit; a withdrawn student keeps history and financial records; record changes requested by parents go through verification.

### A8. Academic Structure and Curriculum

- Subjects per grade with weekly periods, credit or weight, language of instruction, elective groups, prerequisites
- Teaching assignments (teacher, subject, section or group), co-teaching, teacher load view
- Student groups across sections (language levels, electives, support groups)
- Curriculum: units, lessons, learning outcomes, standards mapping (CASE import) *(T2)*, resources
- Lesson plans with templates, weekly plans, coordinator review, **syllabus coverage tracking** against the plan
- **Rules:** a teacher sees and acts only on assigned sections and groups; changing assignments mid-term keeps history.

### A9. Timetable, Calendar, and Rooms

- Periods and bell schedules per stage, rotating and two-week cycles, special day schedules
- Constraints: teacher availability and maximum daily load, part-time staff, room type, split classes, double periods, subject spread across the week, no-gap rules for young grades, shared teachers across campuses with travel time
- **Automatic generation** (OR-Tools), quality score, locked slots, manual drag and drop with live conflict detection, what-if copies, publish with version history
- Views by section, teacher, room, student; print and PDF; iCal feeds
- Substitutions: absence detection from HR leave, ranked suggestions, cover fairness tracking, notification, substitute lesson notes
- Exam timetable, room booking with approval, school calendar with audiences, event RSVPs
- **Rules:** publishing a timetable mid-term does not alter attendance already recorded; conflicts block publishing unless overridden with a reason.

### A10. Attendance and Safety

- Daily and per-period attendance; codes configurable (present, absent, late, excused, medical, school activity, remote)
- Fast entry: all-present then exceptions, seating chart, photos, offline, late-entry edits with reason
- QR, NFC, or kiosk check-in; device integration interface *(T2)*
- Excuse submission by parents with attachment, approval, automatic code change
- Alerts: same-day absence to parents, unmarked-class reminder to teachers, consecutive and cumulative thresholds, escalation ladder to counselor and principal, legal notice templates
- Staff attendance, late arrival, integration with leave
- **Safety:** authorized pickup, one-time QR or PIN gate passes, early dismissal workflow, visitor management with badge printing and watchlist, late-pickup log, **emergency broadcast** with acknowledgement tracking, emergency roll call by location, fire-drill log *(T2)*
- Reports: daily register, percentage by student, section, grade; chronic absence; patterns by weekday; regulatory formats
- **Rules:** attendance locks after a configurable window; edits after lock need permission and reason; an approved leave request pre-fills excused status.

### A11. Coursework and Learning

- Homework and classwork diary, assignments with instructions, attachments, rubric, maximum mark, weight, due date and time, target sections or groups or individual students
- Submission by file, text, link, or **photo from the phone**; late and resubmission policy; similarity note between submissions in the same class *(T2)*
- Grading with rubric, inline comments, audio feedback *(T2)*, return to student, flow into gradebook
- **Homework load view** per section per day with a configurable ceiling and warning
- Resource library per subject and grade, shared by department
- Online quizzes and exams *(T2)*: question bank with types (multiple choice, true or false, matching, ordering, fill-in, short answer, essay), QTI 3 import and export, tagging by outcome and difficulty, randomization, time limits, attempts, auto-grading, manual grading queue, item analysis
- Online classes through Jitsi or LiveKit with attendance capture *(T2)*
- **Kindergarten daily sheet** *(T2)*

### A12. Assessment, Gradebook, and Reporting

- Assessment structure per subject and grading period: categories, weights, drop-lowest, best-of, mandatory components, maximum marks
- Schemes: percentage, letter, GPA, descriptive, standards-based with proficiency levels, pass or fail, effort and conduct grades
- Mark entry grid: keyboard navigation, paste from Excel, validation, absent, exempt, and incomplete codes, comments, change history
- Exams: schedule, rooms, **seating plan generator**, invigilation roster, admit cards, accommodations from special-needs plans, makeup exams
- **Exam paper workflow** *(T2)*: setter → reviewer → approval → secure print request, with restricted access
- Moderation, approval chain, publish window per audience, lock, **grade change request** with audit
- Calculations: term and year totals, weighted averages, GPA, rank (optional), promotion eligibility rules, honors lists, grade boundaries
- **Report Card Studio**: template designer, sections (grades, attendance, behavior, skills, comments, signatures), bilingual, comment bank, AI-drafted comments for review, batch generation, versioning, QR verification, parent acknowledgment
- Transcripts across years, predicted grades *(T2)*, result analysis: distribution, subject comparison, teacher comparison, cohort trends, item analysis
- **Rules:** calculations are reproducible from stored inputs and scheme versions; a published report card is immutable, and a correction issues a new version; late joiners and exempt components re-weight correctly.

### A13. Communication

- Announcements with audience builder (roles, grades, sections, groups, individuals), scheduling, expiry, attachments, **required acknowledgment**, translation, delivery and read analytics
- School news feed and media gallery with photo consent enforcement
- Messaging: one-to-one and group, policies on who may message whom and when, office hours with auto-reply, report and block, moderation, attachments scanning, message translation, search, export for safeguarding under logged access
- Parent-teacher meetings: single bookings and **conference days** with bulk slots, online or in person, reminders, notes and follow-ups
- Surveys, polls, consent forms with simple e-signature (OTP-confirmed, audited) *(T2)*
- **Policy and handbook acknowledgment** *(T2)*

### A14. Notifications

- Channels: in-app, email, push, SMS adapter, WhatsApp adapter *(T3)*
- Templates per event, language, and channel, with variables and preview; tenant branding in emails
- Preferences per user, per child, per category, and per channel; quiet hours; urgent override
- **Digests** daily or weekly; batching of similar events; deduplication
- Delivery log, bounce and failure handling, channel fallback order, SMS credit accounting
- See Appendix C for the matrix.

### A15. Fees and Finance

- Fee items (tuition, registration, books, uniform, transport, activities, after-school), tax per item, fee structures per year, grade, and student category
- Plans and installments, due dates, early-payment discount, late fee rules, sibling discount rules, staff-child discount, scholarships and sponsors, ad-hoc charges and credits
- **Invoice runs** in bulk with preview, approval, and posting; pro-rata for late joiners and leavers; mid-year plan changes
- Payments: cash, card, bank transfer, cheque with due date and bounce handling, online gateway adapter, partial payments, allocation rules, overpayment as credit, refunds with approval, credit notes, write-off with approval
- Payers: guardians, split payers with percentages, companies and sponsors with their own statements
- Receipts with QR, amounts in words, both languages; statements of account; payment links
- Reminders and escalation ladder; restrictions per school policy (for example, hold report card) applied only through explicit, audited rules
- Cashier: shifts, day close, reconciliation, deposit slips
- Reports: collections, aging, outstanding by grade, discounts granted, revenue forecast, cash flow, tax report, defaulters
- Accounting export, e-invoicing plug-in interface, expenses and budgets *(T2)*, purchase requests to payment *(T2)*, general ledger *(T3)*
- **Rules:** posted financial documents are immutable and corrected only by reversing documents; every amount is decimal with currency; rounding rules are explicit and tested; numbering is gapless per series.

### A16. Behavior and Recognition

- Positive and negative categories with points, severity levels, incident reports with involved students, witnesses, location, action taken, follow-up
- Consequence ladder with detentions schedule, parent notification rules, behavior contracts and plans
- Houses and points, badges (Open Badges 3.0 export *(T2)*), awards, certificates, **student portfolio** *(T2)*
- Analytics by student, class, time, location, category
- **Rules:** sensitive incidents restrict visibility; parents see only what policy allows.

### A17. Student Wellbeing *(T2, highest sensitivity)*

- **Clinic:** visits, symptoms, treatment, medication administration with guardian authorization, vaccinations, screenings, allergy alerts pushed to teachers and cafeteria, incident and accident reports, parent notification, sent-home workflow
- **Counseling:** referrals, confidential case notes, sessions, risk levels, safeguarding concerns log with restricted access and escalation
- **Special needs:** assessments, individual education plans, goals and reviews, accommodations that flow to teachers and exams, external specialists
- **Interventions:** created from early-warning flags: owner, plan, actions, review dates, outcome
- **Rules:** separate database, field encryption, access logging, break-glass access, no appearance in general search or Student 360 without specific permission.

### A18. HR *(T2)*

- Recruitment: vacancies, applicants, interviews, offers, contract generation, onboarding checklist
- Staff file: contracts, documents with expiry (residency, license, medical), qualifications, teaching license and **professional development hours**
- Leave types with balances, accrual, carry-over, approval chain, calendar, link to substitution
- Staff attendance, overtime, permissions
- Payroll inputs: salary components, allowances, deductions, advances and loans, payslips, bank file export, pluggable calculation
- Appraisals: goals, **classroom observations** with rubric, self-review, 360 feedback, improvement plans
- Offboarding checklist and clearance

### A19. Operations *(T2 unless marked)*

- **Library:** catalog with ISBN lookup, copies and barcodes, lending, reservations, renewals, fines, inventory audit, reading history
- **Transport:** vehicles, drivers and attendants with document expiry, routes and stops on OpenStreetMap, student assignment, boarding attendance in attendant mode, delay notifications, transport fees, live tracking *(T3)*
- **Inventory and assets:** stores, items, stock movements, issue to staff and classes, reorder levels, fixed asset register with tagging, depreciation export
- **Sales:** uniform and book shop, pre-orders by parents, point of sale, stock link
- **Facilities:** room and resource booking, maintenance tickets with assignment, SLA, and cost
- **Front desk:** visitors, calls, deliveries, complaints and suggestions desk with SLA, lost and found
- **Activities and trips:** clubs and teams with capacity and fees, registration, attendance, trips with risk assessment, consent, payment, and participant lists; competitions and awards
- **After-school and summer programs** with enrollment and billing
- **Cafeteria** with prepaid wallet, allergy check at sale, parent spending limits *(T3)*
- **Boarding** *(T3)*, **alumni** directory and events *(T3)*

### A20. Quality, Inspection, and Governance *(T2)*

- Self-evaluation against a configurable inspection framework, evidence folders linked to live system data, school improvement plan with actions, owners, and KPIs
- Policies library with versions and acknowledgments, meeting agendas and minutes with action tracking, risk register, health and safety checks

### A21. Documents and Certificates

- Template designer with merge fields, conditional blocks, both languages, signatures and stamps
- Certificates and letters generated on demand or by approved request, QR verification page, revocation
- Central document storage: folders, tags, versions, access rules, expiry reminders, retention rules, OCR text search *(T2)*
- ID cards for students and staff, batch printing layouts

### A22. Reports, Analytics, and Data Quality

- Role dashboards (Appendix D), report library, **report builder** with fields, filters, grouping, charts, saved and shared reports, scheduled delivery, export to PDF, Excel, CSV
- Early-warning indicators with explanation; cohort and trend analysis; group-level consolidation across schools
- Data quality center with rules, scores, and fix actions
- Regulatory report templates as plug-ins; open data API for the school's own BI tool

### A23. Administration and Audit

- Audit viewer with filters, before and after values, export, integrity verification
- Job monitor, saga and process monitor, failed-message console with replay
- Import center with templates, validation, dry run, rollback; export center with approvals for sensitive exports
- Recycle bin, data retention jobs, consent records, legal holds
- In-app help, tours, and changelog management

### A24. AI Features (all optional per tenant, all reviewable)

Report comment drafts; message and announcement drafting and translation; summarization of a student's term for a meeting; natural-language queries over permitted data; help assistant grounded in the product documentation; timetable constraint explanation ("why can't this be scheduled?"); anomaly hints on marks and attendance; OCR-assisted data entry; quiz question suggestions from a lesson plan for teacher review *(T2)*.
